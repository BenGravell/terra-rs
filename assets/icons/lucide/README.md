Lucide SVGs from `lucide-static` 1.31.0.
The complete upstream license, including Feather attribution, is in LICENSE.

The selected icons are table, map, info, users, sliders-horizontal, list-filter, and bookmark.
Their upstream license comments are preserved.
`stroke="currentColor"` is replaced with `stroke="white"` so egui can tint the icons.
SVGs are embedded for offline use; Node is not required to build the app.
